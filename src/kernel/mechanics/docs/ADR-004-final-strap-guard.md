# Mechanics semantics 3: final horizontal tunnel roof and floor

2026-09-08. Accepted blocker: 40x30 host, baseH6, strapZ3, strapD4, strapCham0, topBevelShape1/R2. The old successful mesh has only Z hits0,1 at(19.5,0): the top bevel removes the roof. A watertight output is not proof of a valid tunnel.

The guard runs in finish AFTER all source bevels, feature cuts and material partition. It unions the actual final host material parts in manufacturing group0. It uses the exact common tunnel/mouth cutter restricted to the declared footprint, including holes; the exterior lead-in and vertical side mouths are intentional openings. Rotation around Z is applied after this proof and preserves its heights. No parameters, returned vertices, part provenance or material boundaries are modified by the queries.

The first sufficient proof uses the COMPLETE host footprint, a conservative superset of the cutter shadow. It subtracts the final host from the complete vertical columns above the cutter's highest Z and below its lowest Z, bounded by the nominal host body interval. The cutter was clipped to the same footprint prism; no separate projected polygon can shrink the covered domain through XY rounding. The first missing Z (roof) and last missing Z (floor) give measured conservative continuous thicknesses. A disconnected sheet separated from the starting envelope leaves a gap and cannot certify the roof/floor. Thickness is derived from existing final material, never a chosen positive skin. The full-volume residual predicate reuses the existing bounded AsOriginal/Simplify query policy (at most1e-7 mm and additionally bounded by tolerances); this never changes an output material. The budget is subtracted from the measurement.

If that strong uniform condition is unavailable, a second bounded proof checks the actual faceted surfaces. Filling the bounded cutter into a QUERY copy of the final host exposes zero-clearance outer faces where roof/floor is lost. For every overlapping pair of projected triangles, outward-rounded interval arithmetic bounds the complete plane-height difference over XY boxes. Whole boxes are proven outside the triangles, on the unrelated opposite side, or strictly positive. Unresolved boxes subdivide; all remaining boxes must pass. Interior point witnesses can reject but can never certify acceptance. Unknown normal sign, numeric range, depth60 or4,000,000 pair/cell budgets fail closed. Exactly vertical projected faces are recognized geometrically. There is no triangulator, custom solid Boolean, ray-only certificate or vertex weld.

IEEE arithmetic is mandatory: the package targets set /fp:strict on MSVC and -fno-fast-math -ffp-contract=off on Clang. nextafter expands each interval operation. Observed Manifold query tolerance is charged separately. This proof concerns the evaluated faceted solid; the pre-existing curve/Boolean/source whole-pipeline ledger remains explicitly unverified where it lacks a bound.

Opening integrity is constructive: strap subtracts the identical full cutter from EVERY host material. Only partition subtraction follows. There are no post-strap additions. Re-intersecting the same rounded coincident surfaces is not presented as independent evidence. Independent test readback checks the bore, roof/floor, materials and signed profiles.

ABI2 layout is unchanged; arch_mech_semantics_version() now returns3. Source tag extension remains1. Feature guard:strap:roof-floor records [conservativeFloor, conservativeRoof, queryAllowance, boxes, pairs, referenceFaces]. Zero counts identify the full-volume envelope proof. Diagnostic112 states which full-domain method certified the result. Unavailable/nonpositive proofs return AM_INVALID and no mesh/export, with FINAL_STRAP_* or STRAP_GUARD_* diagnostics; input records and previous results survive.

The uniform proof is deliberately sufficient, not an automatic sizing proposal. Complex valid geometry can still receive a typed unavailable result if the finer proof cannot resolve it within its budget. There is no guaranteed physical minimum, hardware fit or slicer claim.
