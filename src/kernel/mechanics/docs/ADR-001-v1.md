# MECH-ADR-001, version 1 — nominal mechanics and source attachment

Historical wave1 decision record. For the current wave2 implementation, read
[ADR-002-v2](ADR-002-v2.md), which supersedes the capability limitations, source
ABI, default groove auto mode, text hosting, bevels and motion sweep below.
The unsupported statements in this historical record are not wave2 results.

Date: 2026-09-08. Status: implemented candidate under the user's technical
authorization. Engine `arch-mechanics/0.1.0`, mechanics C ABI 1. This does not
close O-02 for the source pipeline, or qualify a configured review or physical fit.

1. **Architecture.** A C++17 static library owns validation and the constructive
   feature formulas. It uses pinned Manifold/Clipper2, with internal parallelism
   off. Rust can call its flat C ABI in the same Emscripten link; a second WASM
   instance or JSON mesh transport is not required. No parser, shaper,
   triangulator, boolean implementation, voxelizer or mesh repair is introduced.
   The fixture writer/independent readers are tests, outside the library.
2. **Clearance.** `clr` is one side of an MX cross cavity: length `crossL+2*clr`,
   width `crossW+2*clr`; union two perpendicular rectangles. `gap` is one side
   between cap footprint and tray inner wall. `legoHoDu` is one side, applied
   only for sparse (`nua`/`tu`) masks: bore diameter `legoHoleD+2*legoHoDu`.
   `charmClr` is diametral: socket diameter `charmChotD+charmClr`.
   All positive values enlarge empty space. Negative values are outside the
   catalog domains and fail before publication. These are design gaps, not
   printer compensation. No calibration or slicer compensation is applied.
3. **Z.** All candidate heights retain nominal mm, including `pinD=1.7`,
   `socketD=5.5`, `collarH=1.85`. The schedule is exact integer 1e6 units/mm,
   `z(0)=0`, `z(n)=h0+(n-1)*h`. A layer value uses the interval
   `z(referenceLayer+count)-z(referenceLayer)`. The resolved lower face must
   equal that reference boundary and the declared datum must name the correct
   feature. Otherwise execution fails. Nominal mm intervals report floor,
   ceil and nearest design-end deviations without moving any vertex. Nearest
   ties use the even global boundary index. A moving switch stem's nominal
   height describes reference hardware; its datum is the static switch plane.
4. **Zero.** `ringH` auto uses explicit `AM_AUTO_BODY_HEIGHT` and depends on
   `baseH`; explicit `AM_MM=0` fails. `skirtH=0` disables the skirt, and ribs have
   no side wall to reinforce; it is not automatic height. `strapSlot=0` is a
   circle, `strapCham=0`/`charmVat=0` disable those chamfers, `collarH=0` disables
   the collar, and `rib=0` disables ribs. `legoRanhZ=0` is a literal coordinate
   from the body bottom, not a guess at an automatic center. Its groove
   capability is currently unsupported, including the legacy default-on state.
5. **Source.** `footprint` is already scaled, offset, hole/bridge-policy resolved
   and assigned a provenance ID by the parent. Raw source curves, text and
   artwork remain in the parent graph. Every source-affecting parameter is
   bound by ID/mode/value/datum to the context; missing/stale bindings fail.
   `baseH`/`plateT` are also bound, so prepared slabs cannot become stale after a
   nominal height change. The executor does not infer a body from a bitmap or
   parse an SVG. It retains disconnected footprints and holes, rejects raw
   edges below 2 grid units on both axes, and rejects normalized same-region
   point contacts. No implicit bridge, hole fill, seam gap or epsilon inflation.
6. **Style boundary.** `AM_RAISED_BODY` extrudes the supplied footprint through
   `baseH` (or the cap's `plateT`), then attaches explicit artwork slabs above it.
   `AM_PREPARED_SLABS` takes the entire source/body partition, each with XY rings,
   material and `z0/z1`. Parent must resolve `noi/chim/phang/phang2`, `flatTop`,
   `artH`, `rimOn/rimH`, per-object heights, `layerBand/bandCore/bandCap` and
   their actual visible regions. Prepared slabs must have the declared body
   datum and the lower support footprint. Overlapping XY is valid at disjoint
   Z; overlapping material interiors at the same Z fail. A shared **planar**
   edge in root `ArchSceneView.edges` is not evidence of physical 3D contact.
   Do not use root `arch_scene_build`'s topmost paint-to-column operation as a
   substitute for this already-resolved multi-Z input. This candidate does
   not claim to implement the four artwork styles by testing their interface.
7. **Bounded circles.** Mating pins are inscribed equal-angle polygons;
   radial deviation is `[-r(1-cos(pi/N)),0]`. Bore cutters are circumscribed,
   radius `r/cos(pi/N)`, rotated `pi/N`; deviation is
   `[0,r(sec(pi/N)-1)]`. `N` is derived from half the requested bound and
   rounded upward to a multiple of four, with 8 minimum and 4096 maximum.
   Failure to meet the resource bound is an error. No fixed 18-sided promise
   or half-sagitta compensation. The curve ledger includes an explicit
   +/-2e-8 mm allowance for pinned ClipperD precision 8. Whole arbitrary
   source/boolean error is still unverified and is labelled accordingly.
   Structural XY wall offsets use Clipper2 miter joins, miter limit 2.
8. **Old tolerance fields.** `strapSeg`/`impVox` are retained as legacy
   provenance, not used as runtime geometry quality controls. A user-set legacy
   field is rejected with a migration diagnostic. The domain's existing
   `circle-inscribed-equal-angle` strap tolerance and this executor's
   circumscribed bore convention are different; the adapter rejects an
   unacknowledged numeric transfer. An unselected legacy tolerance stays
   unselected; the request declares the engine tolerance policy separately.
9. **Materials.** First declared source slabs own their exact volumes.
   Structural additions are partitioned against earlier positive-volume
   additions in the same printable assembly. Exact touching planes bypass
   redundant boolean operations. This fixes the retained seed-6d656368 case-1
   regression without moving a seam or changing the oracle. Source material
   overlap is an error, never paint-order replacement. `linkBody` changes
   only non-user skirt/stem roles; user color/slot/provenance survives.
   Prepared slabs declare body/artwork/rim roles. A user slab override has
   priority over a user role override, which has priority over the original
   slab material; color, slot and provenance follow the same winning record.
   Same slot/different colors emits `MATERIAL_SLOT_MISMATCH`, with no remap.
10. **Assembly and proposals.** Main and secondary assemblies have deterministic
    manufacturing placement, with 5 mm XY separation. Preview transforms map
    those manufactured coordinates to the nominal assembly. Changing
    `assemble`/`charmRap` changes only metadata and the export gate; mesh bytes
    are identical. Auto sizing produces a before/after proposal with domain
    applicability, never a changed input. Parent applies accepted changes in
    one domain transaction, regenerates source bindings and rebuilds. The
    catalog-sized depth proposal reserves a declared 0.4 mm test roof; this is
    a candidate design allowance, not a validated printable minimum.

## Constructive formulas

All intervals below are exact design planes. A cutter extended one millimetre
outside a solid is an explicit through-cut domain, not a material-seam offset.

| Feature | Formula and frame |
| --- | --- |
| Keyring | Intersect a ray from host AABB center at `ringAngle` with its AABB; center is a further `outerRadius-ringOverlap` along the ray. Require positive solid intersection with the selected host, add the disk at body bottom, cut the inner bore through the whole resulting host. Concave/disconnected hosts that do not actually meet the disk fail. Text hosting requires a future explicit text-host context. |
| Strap bore | Axis in XY is `(cos a,sin a)`, horizontal transverse axis `(-sin a,cos a)`, vertical profile axis +Z. Center is source AABB center plus transverse `strapOff`, at `strapZ`. `ngang` slot extends horizontally transverse; `doc` extends vertically, by total added length `strapSlot`. Hull of two circles gives the capsule, then extrude through the body. Require positive roof and floor. `rotObj` rotates the final manufactured object about design origin Z. |
| Strap chamfer | For a rectangular host, cardinal bore, circular slot and normal planar mouths only: subtract two 45-degree conical frusta with axial and radial size `strapCham`. Other entry geometries return typed unsupported, including slotted chamfers; they are not quietly made cylindrical. |
| Lego grid | Stable grid indices `(i,j)` centered on design origin, translated `legoOffX/Y`, pitch `legoPitch`. Full keeps all; checker keeps even `i+j`; quarter keeps even `i` and even `j`, including negative indices. Keep a bore only when its entire bore+wall envelope lies in the source footprint. Blind depth begins at body bottom, leaves positive roof. |
| Lego hollow/cross/tabs | Hollow removes the inward wall offset minus bore-boss disks to bore depth. Cross cuts are two rectangles, width `legoXeW`, length `boreDiameter+2*legoWall`. Tabs at +/-X midpoint have declared length/width, neck width, neck length `min(tabLength/3,legoWall)`, and height equal to bore depth; require actual attachment. Elastic/fatigue behavior is unqualified. |
| Cap | Plate underside `U=max(skirtH,postH)`; stem tip `U-postH`; skirt occupies `[U-skirtH,U]` over footprint minus inward offset by `wallT`. Plate/source slabs are translated by U. Hollow source components remain independent. |
| MX | Main post cylinder from tip to `U-collarH`; collar from there to U. Cross cavity opens at tip and ends at `tip+socketD`; require `socketD<postH` and cross outer corners inside both post radii. Ribs bridge the inset footprint to post in the collar band; depth is `collarH` without tray, or `min(collarH,postH-travel-hRecess)` with tray. Nonpositive enabled rib depth fails. |
| Tray | Floor `[0,hFloor]`; pin pocket `[hFloor,hFloor+pinD]`, width `pinW`; body pocket continues by `hSocketD`, width `plateHole`; mouth continues by `hRecess`, width `hMouth`. Boss width `hMouth+2*hBossW`. Outer wall is offset(P,gap+hWall) minus offset(P,gap). |
| Tray motion | Switch plane `B=hFloor+pinD+hSocketD`. Cap assembly translation `D=B+stemH-min(socketD,stemH)-(U-postH)`. Wall top `U+plateT+D+rimOver`. Stop top `U-skirtH+D-travel`, width `hStopW`. All cap/source elements are Z-prisms; extend every nonempty Z-slice interval downward by travel and union those prisms for a continuous swept volume. Reject positive intersection with the static printed tray. This excludes actual switch-body/stem/flex behavior. |
| Charm button | Flange `[0,charmVanhH]`, neck continues by `charmCoH`; bottom flange chamfer has radial/axial size `charmVat` and must be smaller than flange thickness/radius. Integral source body begins at neck top. Separate pin begins at neck top, extends `charmChotH`, and socket cuts upward from separate source body's bottom. Require positive wall and body roof. In preview, separate button translation Z is `-(flangeH+neckH)`. |

## Qualification and open capability

General top/text bevels, rounded/stepped bevel material partition, arbitrary
perimeter semicircular grooves, text-host eyelets and arbitrary-mouth/slotted
strap chamfers are **typed unsupported**. Source-slab composition, source import,
text, imported-mesh CSG, root Worker publish/cancel, slicers, printer profiles,
calibration, coupons and physical force/fatigue tests remain external work.
This is an executable mechanics candidate, **not v1 feature-complete release**.
