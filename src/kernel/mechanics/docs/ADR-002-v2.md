# MECH-ADR-002, version 2 — mechanical v1 surfaces and attachments

Date: 2026-09-08. Engine `arch-mechanics/0.2.0`; mechanics/source C ABI 2.
Implemented under the user's technical authorization. This supersedes wave1's
unsupported capabilities and related formulas in ADR-001. Clearance, nominal
dimensions, role priority and proposal transactions from ADR-001 remain.
This is not physical qualification or configured independent review.

## Stable contract and zero values

Source context is a versioned typed set of normalized footprint rings and
per-material XY/Z slabs. No parser, shaper, triangulator, voxelizer, boolean or
mesh repair algorithm is reimplemented. Manifold and its pinned Clipper2 perform
solid/planar operations. Parent supplies visible source regions and style slabs.
The planar edge ledger never establishes contact between disjoint Z intervals.

`clr`, tray `gap` and sparse-grid `legoHoDu` are **one-sided** clearances;
`charmClr` is **diametral**. Positive enlarges void space. Negative is rejected;
tray gap must be strictly positive. No printer compensation is applied.

`z(0)=0`, `z(n)=h0+(n-1)h` uses integer 1e6 units/mm. Layers specify an explicit
datum and global interval; nominal mm report schedule deviations without moving
to a layer. In particular 1.7, 5.5 and 1.85 mm stay exact design values.

`AM_AUTO_BODY_MIDPOINT=4` is legal only for `legoRanhZ` with stored value zero.
It resolves to `baseH/2`. The native default uses this explicit mode; the adapter
emits it only for catalog auto-origin zero. **User-origin zero stays literal Z=0**
and produces the groove clipped at the body bottom. ABI-1 persisted documents
need a versioned migration in the parent; an explicit scalar is never guessed
automatic. `ringH` auto still means **body height**, even on a text host. Explicit
mm zero fails. `skirtH=0` disables the skirt. Disabled values and source bevel
overrides remain in effective parameter/dependency records.

## Semicircular perimeter groove

Subtract the radius-R tubular neighborhood of each external footprint boundary
polyline at `Z=bodyBottom+legoRanhZ`. Positive-area external rings participate;
hole rings do not. Edges use extruded circle cutters; vertices use enclosing
spheres from the pinned library. Union cutters once and apply them to every
labelled slab, preserving material divisions. This is a semicircular inward
section. Default R=.8 and body H=5.6 give Z=2.8.

The circle is circumscribed with analytic overshoot bound. A library sphere has
insphere radius `min(abs(dot(n,v))/|n|)` over its face planes. Scale by
`R/insphere` to enclose the analytic sphere; its maximum vertex radius bounds
overshoot. Double sphere resolution until overshoot <= tolerance/2. Record
negative material displacement in curve side 3. No fixed segment count promises
accuracy. Require positive top roof and a surviving inward component at R.
Maximum 256 external edges and sphere resolution 512. Source holes and islands
remain; a literal zero groove is intentionally clipped by the bed-side boundary.

## Top and text bevel/fillet

For a source patch with top T, subtract XY covered by another patch continuing
above T. The remainder is its exposed top. Body/artwork/rim obey `topBevel`;
text/text-base obey `bevelChu` independently. `bevelGop=true` unions compatible
same-Z exposed tops before creating a cutter, keeping shared color seams.
`false` intentionally bevels individual regions, creating valleys. User source
overrides target exact body/slab IDs with their own enabled/radius/shape/steps.

Let d(z) be inward distance from the exposed top region's boundary:

| Shape | Geometry |
| --- | --- |
| Round, 0 | On `[T-R,T]`, `d=R-sqrt(R²-(z-(T-R))²)`; rolling quarter-circle. |
| Chamfer, 1 | On `[T-R,T]`, `d=z-(T-R)`; true 45-degree chamfer. |
| Steps, 2 | Last N global schedule intervals meeting T. Step i removes width `R*(i+1)/N`; its upper plane is the next boundary except the last, which is **exactly T**. |

Smooth/chamfer surfaces sweep one-sided inside strips along each edge and rolling
sectors only at reentrant corners. Library extrusion/revolution/boolean create
the solid. Convex corners are covered by incident strips; full balls there would
introduce redundant geometry. Profiles use a local datum with zero-radius tip
**exactly Z=0**, extend through the top, then clip once at exact T. This avoids
nanometre membranes from separately rounded absolute profile Z. No epsilon
changes a material seam. No Simplify or mesh repair is applied.

Round-profile chord sagitta is <=exportTolerance/4. Corner sectors and step offset
arcs each reserve <=exportTolerance/4 plus the explicit ClipperD quantum ledger.
Steps use round insets and exact annulus extrusion per interval. The common
cutter applies to **all** source slabs, crossing vertical material changes
consistently. Source/boolean errors are not certified by local flattening bounds.
Reject a radius erasing a component/material or beginning without strictly
positive support below it. Thin unsupported glyphs cannot accept deeper fillets;
nominal plate/post/socket dimensions are never changed to accommodate them.

## Explicit text attachment

`ArchMechAttachment` supplies a stable ID, role, footprint and lower/upper Z.
Text/text-base slabs reference that ID. Validate footprint against the union of
member slabs at the bottom and validate actual Z extent. Parent supplies shaped
glyphs, counters/dots and this footprint; mechanics does not estimate them from
glyph names or an image.

`ringTren=chu` selects `eyelet_attachment_id`. Use its footprint AABB/ray at
`ringAngle` for placement and actual post-bevel text solids for contact. The
eyelet datum is `bodyBottom+attachment.z0`. Require positive intersection of the
**final annulus** with selected text. Missing/orphan host, inconsistent footprint,
zero wall/overlap or no attachment rejects with no output mesh. Source holes,
detached marks, roles/materials/provenance survive. `source:attachment.bottom`
is the adapter datum name for this selected host, not the main body's underside.

## Capsule and oblique strap mouths

Local axes: u horizontal transverse, v vertical, s bore axis. `strapSlot` is total
added segment length: `ngang` along u, `doc` along v. The capsule is the library
hull of equal circles. Chamfer c is an **axial** lead-in: radius grows from r to
r+c over axial length c; straight segment length stays unchanged. It is not
normal-distance c on a slanted wall. This convention preserves the user's angle.

A footprint edge gives `s=s0+m*u`. Construct a conical-frustum profile (hull of two
for a capsule), shear by `s += m*u`, clip only to actual edge projection endpoints.
Adjacent mouth pieces meet at their true common boundary, including a 45-degree
bore crossing a square corner. A full mouth is not clipped tangent to its own
profile. Each cutter extends 1 mm beyond its wall; reject if that continuation
intersects another source wall. Extension avoids coincident cutter caps; it
does not shift material surfaces.

For radial perturbations before shear, maximum amplification is `sqrt(1+m²)`.
Divide local flattening budget by the maximum active-edge factor. Publish both
local radial (`frame=1`) and manufacturing Euclidean material (side 4, frame 0)
bounds. Do not interpret the first as a world circle. Require positive floor,
roof and lateral containment, <=512 edges, |m|<=1000, <=4096 circle segments.
Unsupported geometry resources/adjacent-wall cases reject explicitly; valid
cardinal, oblique, capsule and corner-mouth normals have geometry and measurements.

## Continuous cap/tray assembly check

Prisms use exact Z-interval extrusion by travel. For beveled faceted solids,
union the original solid with library convex hulls of every downward-facing
triangle and its translate by `-travel*Z`. This exactly sweeps the faceted boundary
along a segment, including slopes, without middle-slice approximation. Intersect
the union with the static printed tray; positive collision rejects. Maximum
50,000 triangles per piece. Independent numeric tests intersect cap/tray sections
at multiple travel positions; they do not trust the executor's boolean gate.
The switch's hardware/flex model is not part of the printed-solid check.

Print layout separates secondary assemblies by 5 mm. Assembly mode changes only
preview metadata/export gate. Vertices and intervals remain manufacturing data.
Auto sizing returns a proposal/diff followed by an explicit parent transaction
and regenerated source; no input mutation.

## Resources, cancellation and qualification

Maximum inputs: 200,000 grid points, 1,024 slabs, 256 attachments, 1,025 bevel
overrides; 1,000 mm footprint span and +/-10,000 mm coordinates. Outputs: 2,048
pieces, 8,192 features, 2,000,000 triangles. Additional limits: 512 sweep edges,
256 arc profile subdivisions, 2,048 revolution/offset subdivisions and 4,096
grid candidates/sweep intervals. Failures return diagnostics with no partial mesh.
These counts are not a hard memory/time guarantee for library boolean complexity;
the parent allocation policy and watchdog remain necessary.

`ArchMechControl` owns the pinned `ExecutionContext`, single-use flag and generation.
Cancel only the exact generation. Builder checkpoints and
`mesh.WithContext(context).Status()` observe deferred evaluation before subsequent
queries. The actual header says `Volume`, `GetMeshGL`, `BoundingBox` and other
queries do **not** themselves observe an attached context; derived Manifolds drop
that attachment. Eager operations have documented context entry points. Some
constructors, 2D operations and queries still run without cooperative interruption.
Current evaluation progress is separate from stage and is not whole-job monotonic.
Single-thread WASM cannot receive a JS callback while synchronously inside C++:
parent needs its shared-memory observer or Worker watchdog and generation gate.

Root primary-lease transfer and increasing generation remain authoritative.
Mechanics ABI 2 does not replace that manager. Both builds reuse read-only pinned
Manifold and separated original/derived Clipper2 trees, with downloads OFF.
The matrix separates measured mechanics, invalid controls and parent dependencies.
All five products/four mating families are trial geometry. Arbitrary imported-mesh
CSG, source style generation, full-pipeline error, arbitrary self-intersection,
browser/runtime integration, slicers and physical force/fatigue remain separate
qualification. A field count or topology flag is not a full application v1 pass.
