`Manifold-Apache-2.0.txt` and `Manifold-AUTHORS.txt` are unmodified copies from
the pinned Manifold tree. `Clipper2-Boost-1.0.txt` is an unmodified copy from
the exact Clipper2 archive pinned by Manifold. Revisions, hashes, static-link
configuration and the upstream no-iostream carry patch are listed in `pins.json`.
`clipper2-no-iostream.patch` is an unmodified copy of that carry patch. Builds
reuse the separately hash-verified derived tree; they do not patch the originals
or download dependencies at configure time.
Retain these notices when distributing the statically linked library/module.

The C++/JS candidate and synthetic rectangle/hole/color test recipes are new
project implementation work. This package does not assign a new license to the
project. It bundles no fonts, raster artwork, printer settings, private fixture,
system configuration, credentials or generated user media.
