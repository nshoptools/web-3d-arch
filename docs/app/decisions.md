# Implementation decisions and remaining gates

- Implemented AppBridge 0.3, with SourceResult.preview separate from editable raster. Trusted PNG display bytes require bounded dimensions, finite mm scale, complete signature and matching IHDR dimensions; the parent decoder/encoder remains responsible for actual codec correctness. SHA-256 and references preserve those bytes across save/open/history. Original SVG is not displayed.
- Dedicated Worker editing is the production default. The adapter creates a fresh existing editing Worker per gesture and terminates it after commit/cancel/failure. This trades initialization/copy overhead for explicit private-state lifetime and avoids keeping an independent editor history that could conflict with project history. No duplicate pixel algorithm. A portable Worker PNG encoder is supplied by parent; test-only DOM PNG encoding is not product evidence.
- Native lease ownership and transport generation remain separate from ticket/revision. The default wrapper keeps original KernelLease in WeakMap for native Rust STL. Only parent can qualify actual native geometry, mechanical fit, printers and hardware.
- State/history publication uses storage CAS. GPU is a later rebuild with a separate visible revision. Failed/stale/cancelled builds keep old committed rendering; an old model is not offered for current-state export.
- Proposal.accept verifies the exact prepared output bytes, live head/revision and identity epoch; proposals are not recomputed using new defaults. History pruning and product switch use the same exposed command. Raw source conversion remains confirmed. Adapter proposals cannot be bypassed through preview commit.
- OPFS policy is prefer-opfs with fallback only on unsupported or fresh verification-failed. WebKit on this installed runtime returns a zero-length file after probe close; IDB fallback is an actual tested path. No fallback during a commit, no physical power-loss durability claim.
- Ed25519 WebCrypto is the default lease gate. Installed WebKit reports NotSupportedError. Optional allowAuthenticatedLeaseResponse is explicitly false by default and accepts only a just-received authenticated HTTPS response when that algorithm is unsupported. Parent decides whether deployment permits this online assertion mode or supplies a verified cryptographic alternative. Offline resume still requires externally established trust.
- Controller does not persist provider keys, tokens, cookies, signed lease payloads or session secrets. Reset terminates private adapters before another identity is opened. Per-user IndexedDB/OPFS namespaces come from main storage.
- History uses main plan/restore/accept helpers, 20 transactions/24 MiB and deduplicated refs. A newly committed verified document can populate its library metadata directly; re-reading every history asset after each save is unnecessary. Open/import still verify bytes and schemas.
- Spent is null because the backend job list is not an authoritative aggregate ledger endpoint. Reserved counts page through reserved/submitted/running/unknown, including closed unknown jobs with outstanding money. Backend remains the authority for all budgets and billing.
- OIDC same-tab HTTPS navigation from trusted /auth/start is implemented, as authorized. No external fetch/script exemption. Invite URLs refer to exactly bound issuer+subject, and no email is sent.
- 0.3 has no unknown-product library union or multi-credential picker. Expose controller.unrecognizedProjects/raw rescue and AI_CREDENTIAL_SELECTION_REQUIRED instead of invented identities/default credentials. Settings import/reset conflict details remain in actual backend conflict copies; normal update also exposes them in snapshot.
- Cloud replication, imported-mesh processing, broad source codecs and export formats remain capability-gated pending actual parent adapters. No geometry or 3MF implementation is part of this candidate.

Earlier diagnostic test runs are retained. A WebKit history test exceeded the initial 180-second case bound; the final harness allows a bounded 360 seconds and reports unavailable capabilities separately. A superseded full browser run was intentionally stopped before the final candidate revision; it is not physical-crash evidence. Final evidence is identified only by the checked handoff manifest.
