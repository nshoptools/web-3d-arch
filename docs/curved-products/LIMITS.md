# Checked scope and remaining integration

This delta addresses the 22 reproduced PSB-03 default refusals using actual
prepared Inter O and selected Noto Emoji sources. The 40-model matrix spans
five products and four modes for those two sources. It is not a claim about
every possible font, raster, SVG, arbitrary imported CSG or parameter choice.
The separate derivatives explicitly test three sizes, first/regular schedules
and mating tolerances without reinterpreting the other nominal inputs.

The final candidate retains existing guards against point contacts, tiny raw
edges, invalid source support, impossible walls/roofs, plugged openings,
unmatched bindings, cancellation and resource overrun. A rejected model has no
published mesh. The normal-path matrix requires real geometry and independent
oracles; a resource refusal never counts as a feature pass.

The groove has bounded primitive/frontier/evaluation work; strap processing
bounds all scanned points and only counts geometrically active mouth edges
toward its 512-edge cap. General top/text boundary bevel sweeps still retain
their existing 512-edge limit outside this bounded remediation. A dense source
that also enables such a bevel can be refused. No tolerance or radius is changed
to fit a work budget. Count budgets do not impose a hard memory/latency limit
inside an individual Manifold operation. See ADR-CP-001 for exact limits and
the header-specific cancellation behavior.

Roof/floor sufficient proofs query the final material union and deduct their
explicit numeric budget. Manufacturing geometry is not altered by those
queries. The tests include after-bevel holes, detached roofs/floors, thin valid
skins, oriented section integrals for all preserved source materials, and
numeric ray/section comparisons. Sampling is regression evidence; it does not
replace the production complete-volume/faceted-domain guards or establish a
global Hausdorff bound for every operation in the full source pipeline.

Native and Node WASM use the same static child targets plus the unchanged
borrowed product bridge. WASM NODERAWFS is fixture I/O only. Production Rust
registry, current-head authority, browser Worker cancellation, ASFR/runtime
integrity, actual renderer and final exports are the parent's integration.
The newer parent `module-source-r1` pair is not substituted for the recorded
95022588…/211b392f… source capture. This candidate proposes no root hook.

Manufacturing doubles, unqualified fit and preview transforms retain their
existing contracts. A downstream STL float collision must still be rejected or
handled by the separately consented root proposal path; this delta does not
snap or merge export vertices. No printer, slicer, mechanical fit or whole-app
release qualification is asserted by these component results.
