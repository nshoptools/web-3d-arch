# Image codec and resource decisions
This is image preparation, never manufacturing geometry, vectorization, print fit, physical scale or full color management.

PNG is decoded genuinely using Node zlib for bounded inflate, then explicit PNG8 scanline reconstruction (filters0..4), palette expansion/tRNS and grayscale/RGB/RGBA conversion. Every chunk CRC/order/length, complete compressed stream consumption, decompressed scanline count, palette index and filter is checked. Supported static noninterlaced8-bit types0/2/3/4/6. Unknown/animated/compressed-metadata chunks are refused. Standard sRGB gAMA45455/cHRM accepted; custom gamma/chromaticity and ICC rejected. Supported ancillary pHYs/tEXt/tIME/bKGD/sBIT do not change raster samples; originals retain those bytes. No physical units inferred from pHYs.

JPEG uses unmodified jpeg-js0.4.4 decoder (source renamed .cjs for explicit Node ESM interop). A bounded marker/frame pass runs first, accepting baseline8-bit grayscale or three-component JFIF YCbCr, sampling factors1/2 and totalMCU blocks<=6. Progressive/extended, multi-scan baseline, CMYK/Adobe, EXIF, ICC and non-JFIF APP metadata are explicit unsupported cases. Original encoded top-left orientation retained; EXIF is not ignored or applied silently. Full entropy/Huffman/DCT decode uses tolerantDecoding:false, maxResolutionInMP4.194304, maxMemoryUsageInMB96. Package decoder comes from jpeg-js registry release git9ccd35fb5f55a6c4f1902ac5b0f270f675750c27; provenance manifest retains tarball SHA256/SHA512, per-file SHA and licenses. No global dependency install or native build.

Uploads<=8,000,000encoded bytes; output<=12,000,000 (also narrower existing quote byte cap where applicable). Width/height<=4096input and2048output, pixels<=4,194,304. Validate size before large allocation. RGBA<=16,777,216 bytes, PNG scanline inflate<=16,781,312. These are narrower than LIM-01's32MB/64Mpx ceiling.
Decoder runs in a fresh Node worker_threads isolate per image; at most two concurrent workers and no waiting queue. Default5s wall deadline (testable range1ms..10s),128MiB old heap,16MiB young heap,4MiB stack, plus separately bounded encoded/external buffers and JPEG allocation budget. Node heap limits do not cap process RSS; transient copies/JSON/base64 and decoder buffers add to peak memory. This is bounded by format admission and concurrency, not a measured cross-machine RAM guarantee. Worker flags are explicit execArgv:[] so test runner/inspector flags do not leak into decoding workers. Workers terminate after completion, rejection, deadline or signal. Caller sees typed failures, never partial bitmap.

A real thumbnail is PNG RGBA8, longest dimension256, rounded positive other dimension, nearest source-pixel center sampling; no hidden color reduction, background flattening, alpha blending, blur or crop. Transparent samples retain hidden RGB. Deterministic same codec/runtime input yields same PNG; encoder is Node zlib level6, filter0. Output<=270,000 bytes. PNG and JPEG sampling are unmanaged sRGB conventions, no calibrated/print color claim. Original bytes are never overwritten by the thumbnail.

Ingress: one global upload body reader; authenticated own quotas;8 retained originals and32MB original+thumbnail per user,40decode attempts /64MB input per UTC day. Shared total storage additionally includes retained original+thumb,512bytes reference metadata and one object; deletion/expiry preserves quota-charged replay metadata. Reader protected by existing HTTP body/deadline/origin/CSRF gates. Invalid decode consumes ingress counts; exact successful replay returns stored descriptor without decode.

Fixture correction: old tests/server/helpers.mjs used a1px PNG with invalid IDAT CRC4019901157; actual CRC4020414299. Its inflate bytes are [1,255,255], producing opaque white gray+alpha after Sub reconstruction. Success fixture changes only four CRC bytes; original malformed bytes retained verbatim in a negative analytic test. Assertions on result/source hashes use the corrected actual bytes, never relax the decoder. Fixed20ms test settlement wait became a bounded state poll because settle now awaits a real worker.
