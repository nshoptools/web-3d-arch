## Limits and unsuccessful setup attempts

No whole-pipeline/printer-fit or ambient-isotopy proof. Conditioning is the narrow
pair-edge union-STL capability described in PROOF.md. Nested/interlocking
components, aliases, larger clusters, out-of-range exact arithmetic, unproven
orientation or work/resource exhaustion fail typed. Material ZIP/SVG conditioning
is unavailable. The app's real consent/CAS/independent checker and export adapter
remain parent-owned; source/material gates in these fixtures are explicit test
inputs, not an application qualification claim.

The first CMake command needed quoting of the3.5 policy value. An initial Rust
check pointed to the earlier geometry-only archives and correctly lacked the
root archive; it was rerun against the unified build. Browser staging initially
missed transitive text/input dependencies, then captured them. The legacy Worker
intentionally exposes `INVALID_SERIALIZATION` as code while the native test
asserts exact `STL_FLOAT_COLLISION` detail; the test expectation was corrected to
that existing contract. Floating summation of cube volumes was replaced with an
exact integer determinant oracle, not a geometry tolerance relaxation. Installed
TypeScript requires `--ignoreConfig`; its corrected invocation passes. The
read-only toolchains do not include rustfmt; the attempted formatter did not
change source. All setup failure logs remain in the private run. None is counted
as a product pass or hidden by a timeout increase.
