# Selected whole-product acceptance matrix

This is a bounded functional/UX campaign, not all QA-03 campaigns or slicer/physical qualification. Every selected row gets a record per browser; no unexecuted row is counted as pass. Requirements map to the current repo specification; existing AT check IDs will be attached from tests/acceptance/cases.json when the specific actions match.

| Case | Requirements | Actual action / observation | Oracle and scope |
| --- | --- | --- | --- |
| PROD-01..05 | MOD-01/02/03, ARC-01, QA-01/03 | Create keychain/clicky/strap/lego/charm through compiled UI; normal source/default setup; build | Actual product route, Worker/WASM inventory, committed visible model, materials and export gate. Native curved failures stay open, never count refusal as product build pass. |
| FLOW-SVG | GEO-01/02/03, DAT-01/03, EXP-02 | Import two-color SVG with hole, edit size/thickness, build/view, undo, save/open, rebuild, STL download + receipt | Read actual downloaded artifact; finite triangles, nonzero volume, topology, bounds/units, material part map and receipt exact hashes/revision. Do not apply pure extrusion volume formula to a manufactured product. |
| FLOW-RASTER | SRC-01, EDT-01, GEO-01 | Import a real PNG with transparent region, explicit preparation/consent, edit + undo/reopen, actual product build | Raw PNG and current/provenance asset hashes, no premature commit, actual Worker results and readback when enabled. Pending reconversion capabilities stay open. |
| FLOW-TEXT | SRC-04, VEC-01, GEO-01 | Vietnamese NFD text using original pinned font; preview/consent/build/save/open | Original string/font bytes/provenance retained; normalized/shaped result and detached marks accounted for; no system font substitute. |
| FLOW-COLOR | SRC-02, UI-04, GEO-01 | Select colored library artwork from original catalog/assets; accept explicit simplification when required; build | Exact asset routes/hashes, colored original source and material bindings preserved; never substitute monochrome or a placeholder. |
| FLOW-CANCEL | ARC-01, DAT-01, UI-03 | Cancel a running actual build, trigger malformed input/failure and stale job against new state | Prior committed model/head retained, matching-model export gate truthful, no late publication or leaked private worker state. |
| PROFILE-UI | ACC-03, UI-04/05/06 | Without project: import normalized profile, confirmation, download original, replace/delete, account-specific roundtrip | Real UI + HTTP ETag/SQLite. Byte equality, no write before consent, no project receipt, qualified false and incoming-file wording. |
| ACCOUNT-UI | ACC-01/03/04, AI-01/02/03 | A→logout→B→A; compare private project/settings/profile and costs; use only local explicit provider | Real own-user API responses/DB rows and UI reset. B cannot use A's key or costs; no shared/owner fallback. Not full backend attack suite. |
| UX-320/1280 | UI-01/03/05/06 | Critical create/import/build/save/export and profile dialog at 320 and 1280 CSS px; keyboard search/Escape/focus return | Screenshots inspected, visible reachable controls, no unintended horizontal overflow/occlusion; preserve exact CSP screenshot-tool footprint separately. This is not a blanket WCAG claim. |

Result classification: failure of a selected oracle => fail/exit 1; missing artifact/capability/witness or bounded timeout => unverified/unsupported, exit 2 unless a failure already dominates. Required finite time budgets are declared per operation and kept in evidence. Raw exceptions, failed downloads and incomplete results are retained for parent fixes.
