The extended suite reports 25 groups per engine, not 25 independent product
features. It includes the original18 groups plus seven focused callback groups.
The final promoted snapshot passed Node24.19.0, Chromium153.0.8010.12, Firefox155.0
and WebKit26.6:25 groups each, with typed checks, parity, transfer, active cancellation
and actual Worker termination. Relocation passed2 checks and reran25 Node groups.
That final main snapshot already contains the parent's prepared-to-ready correction;
no component overlay was applied. Earlier failing TDZ and patched probes are kept
separate in the implementation report.

Read the exact run report and staging digests for pass/failure and any explicit
component patch; a report on a patched candidate is not a PASS for an unmodified
main component. Missing engine coverage is never silently skipped.

Tests invoke production raster hooks in a dedicated one-Module Worker test host.
The main EngineClient/raster RPC and application compositor are parent owned and not
qualified by this suite. SourceOperations/ProposalOperations/receipt validators are
real current main; persistence/epoch and editing effect use a declared in-memory host.
This is not a backend authentication/online-policy/cross-tab-CAS security test.

The selected main binary exposes raster, HarfBuzz and printing in the same module.
Callback cases execute product prepare/build and source-ledger/APMS ownership for
one authored grid with default keychain settings. This is not exhaustive product or
mechanics qualification. Export presence does not test HarfBuzz or 3MF correctness. No new native Rust build occurs in this JS suite.

The original Rust corpus has additional adversarial/codec/regeneration cases;
this promotion does not relabel those unexecuted cases as JS PASS.
The processor's certificate remains the authority for topology/error embedding;
JS checks typed structure/incidence. Unknown source approximation bounds remain
unknown. Exact indexed nm coordinates do not qualify printer fit, shrinkage or mesh.

Preview PNG shows editable pixels or the processed label grid, not smoothed contours.
Anisotropic downsampling retains two physical axes; scalar preview may be omitted.
No implicit matte, unsupported-format fallback or lossless conversion claim is made.

These are implementation tests. Independent review, whole application integration,
slicer, physical fit and manufacturing acceptance remain separate.
