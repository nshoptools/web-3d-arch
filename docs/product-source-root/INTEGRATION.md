`ProductTransactionsAdapter.prepareAdoption({control,state,source,assets,materials,materialDefaults,operation,sourceAuthority?,text?})` and `prepareCommand({control,state,assets,command})` return an exact `arch-product-transaction/1` plan. `preview()` supplies bounded prospective state/new owned asset bytes. `confirm(control)` is one use. `replan(control,index)` creates a fresh native probe after explicit face alignment consent; it never commits a geometry correction. Always `release()` in controller ownership cleanup.

The new controller transaction mixin seals state + assets + native head, gets explicit approval, confirms native once when layer datums are queried, and commits through existing history/CAS once. A model is rebuilt from the committed head. Requests with no unresolved layer targets do not manufacture a native datum receipt: they use the source/material adoption proposal and ordinary post-commit product build. A native refusal after such an adoption leaves a valid retained source and no manufactured model.

Raster acceptance uses `acceptProposal(input, consume)`: the source receipt is checked with the original ticket; a fresh job owns the product plan. The closure retains an independently owned planar SourceContext built from the accepted 31-buffer graph, including its exact sealed full-image frame. The private authority is a WeakMap capability, never serialized. Retained contexts are released on confirm/discard/reset. Edited raster stores a bounded hash-linked edit chain; later segmentation requires explicit rebind and preserves proven identities and original/full RGBA. Same slot/different color still blocks.

`text.update {values:{...,asSource:true}}` now prepares real UTF-8 text input with staged settings and runs the same atomic source adoption. A `baseState` extension on ingest is limited to a text-only prospective state at the same revision; live guards remain bound to the original state. Source artifacts are freshly shaped in the root Module, not metadata toggles. Text-as-source has artwork semantics: effective product size/art mode/artwork/body parameters govern manufacturing. Overlay height/base/placement values remain stored inactive and are disclosed in the consent changes and `metadata.productSourceRole`. Bevel remains explicitly blocked. Replacing the source with an image turns off asSource in the same atomic edit. Text removal in source mode removes source/text together.

`withValidatedRegions(input,consume)` remains available for the parent source-SVG exporter; it supplies owned checked contours, region metadata, source bytes/provenance and frame without constructing product mesh. Existing source bytes, font assets, Unicode and raw encoding remain retained. The product material contract remains in `src/contracts/product-material`; no move back into integration.
