# Kiểm vòng đời chuẩn bị và xuất tệp

[Kết quả](verification.json) gồm bảy ca chuẩn bị/kiểm tra mô hình và tám ca
cấu hình/hồ sơ xuất. Tất cả đạt trên controller thật; store/exporter/mesh trong
phép kiểm là đối tượng thử có nhãn, không dùng làm bằng chứng hình học hay
nghiệm thu ứng dụng.

Phạm vi gồm lease/ticket hiện hành, hủy và kết quả muộn, đổi tài khoản,
gộp tác vụ, danh sách máy in khi nguồn lỗi, cấu hình được lưu vào lịch sử,
hash hồ sơ và xác nhận xuất trước khi tạo/tải tệp. Xem
[hành vi điều phối](../../app/preparation.md).
