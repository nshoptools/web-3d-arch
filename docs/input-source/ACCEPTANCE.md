# Acceptance mapping and verification scope

Tests are implementation self-verification. No independent review seat was launched or claimed. Assignment inherits Astra/max; the actual fast setting is not exposed to this implementation. The required root/development/input/review instructions and official project specs were read. No child agents, main changes, editor-wave1 changes, machine configuration or dependency downloads were used.

The 1,380-byte analytic COLRv1 font is original test artwork generated by make-paint-fixture.py using repository FontTools 4.64.0. It has seven glyph paints with known geometry/colors, no upstream font subset or alteration. Its deterministic SHA-256 is f30601e117de679a319ba7aafe1560b1a8ce1410a44736cfef87de6042bceb69. FontTools remains a test-only dependency, read-only from .toolchain.

Browser harness: pinned Playwright 1.63.0, Chromium 153.0.8010.12 / Firefox 155.0 / WebKit 26.6, launched sequentially. A private 127.0.0.1 ephemeral port serves only an exact byte whitelist; route interception and server Host/method/path validation reject other requests. Engine WASM, original fonts and parent reader files are read-only. Profiles, artifacts, reference records, PNG evidence and reports stay in this run. No raw source SVG is inserted into a live document.

WebKit on this Windows build has no Worker OffscreenCanvas. Its normal source extraction/layout tests run, and direct Worker native-preview requests explicitly verify source-preserving renderer-gap. Seven checks specific to direct Worker canvas pixels/confirmation remain skipped. A separate real Worker-to-main bridge runs all 31 checks successfully, rendering original COLRv1/CBDT through detached HTML canvas. Chromium/Firefox qualify the same bridge using main-thread OffscreenCanvas; that capability is checked separately. No source switch, fake bitmap, system font, raw SVG DOM or object URL is used. Actual native timings and animation-frame gaps are evidence, not preemption or frame-latency guarantees.

Checked results, exact counts, parent module hash and artifact inventory are recorded in HANDOFF.md and the run's evidence/checked-manifest.json. Snapshot/mesh creation is limited to the existing parent parser/extruder integration check; this candidate implements no geometry core. No total source bound, micron geometry, manifold result across all sources, slicer, print or fit acceptance is claimed.
